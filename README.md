# SquadPan — app Android

L’application des réunions et activités du BDE : reçois les nouvelles réunions de tes squads en notification et réponds en un geste.

## Installer

1. **[Télécharger SquadPan.apk](https://github.com/Taoufic67/squadpan-app/releases/latest/download/SquadPan.apk)** depuis ton téléphone Android.
2. Ouvre le fichier téléchargé. Si Android le demande, autorise ton navigateur à installer des applications inconnues.
3. Appuie sur **Installer**, ouvre SquadPan et connecte-toi avec ton compte BDE.
4. Accepte les notifications pour être prévenu·e des réunions.

Le contenu de l’app se met à jour tout seul. Une nouvelle version n’est publiée ici que pour les nouveautés de l’app elle-même : retrouve-les dans [Releases](https://github.com/Taoufic67/squadpan-app/releases).

Sur iPhone : ouvre le site SquadPan dans Safari, puis Partager → « Sur l’écran d’accueil ».
